Como Conectar o Supabase Gratuito em 3 Passos

  1. Passo 1: Criar Conta Acesse supabase.com, crie uma conta grátis e crie um projeto chamado catalogo-produtos.
  2. Passo 2: Criar a Tabela No SQL Editor do Supabase, execute o código abaixo para gerar a estrutura de produtos:
    create table produtos (
      id bigint generated by default as identity primary key,
      title text,
      price numeric,
      description text,
      image_url text,
      whatsapp text
    );
  3. Passo 3: Salvar Chaves Vá em Project Settings > API no Supabase, copie a URL e a anon key e cole no botão "Configurar Banco" acima!
